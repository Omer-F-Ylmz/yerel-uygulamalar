# yerel-uygulamalar

Streetball Hero'yu kendi bilgisayarında çalışan yerel bir sunucuyla oynatma projesi.

Bulut oturumundaki Claude işi bu repoya yazar. Sen bilgisayarındaki
`C:\Users\pc\Desktop\yerel streetball` klasöründen çekip çalıştırırsın.

## Klasörler

| Klasör | İçerik |
| --- | --- |
| `sunucu/` | Oyunun bağlanacağı yerel sunucu (Python) |
| `apk/` | Orijinal ve yamalı APK. Git'e girmez, Google Drive'dan gelir |

## Güncel hali çekmek

Klasördeki `guncelle.bat` dosyasına çift tıkla.
